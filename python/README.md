# Python版 顧客フォルダ作成スクリプト

Googleスプレッドシートから顧客情報とフォルダテンプレートを読み込み、Googleドライブにフォルダを一括作成します。

## 機能

- Googleスプレッドシートから顧客一覧を読み込み
- フォルダテンプレートの階層構造に対応
- 対象区分（共通/法人/個人）によるフィルタリング
- 既存フォルダはスキップ（重複作成しない）
- 空のフォルダのみ削除可能
- 旧フォルダの整理（テンプレートにないフォルダをアーカイブへ移動して削除）

## セットアップ

### 1. Google Cloud Console で認証情報を作成

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. プロジェクトを作成または選択
3. 「APIとサービス」→「ライブラリ」から以下を有効化:
   - Google Drive API
   - Google Sheets API
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - アプリケーションの種類: デスクトップアプリ
5. 作成した認証情報をダウンロードし、`credentials.json` として保存

### 2. パッケージをインストール

```bash
pip install -r requirements.txt
```

### 3. スクリプトを編集

`create_folders.py` の以下を設定:

```python
SPREADSHEET_ID = 'あなたのスプレッドシートID'
PARENT_FOLDER_ID = '親フォルダID'
```

### 4. 実行

```bash
python create_folders.py
```

初回実行時はブラウザで認証を求められます。

## 旧フォルダの整理（クリーンアップ）

テンプレート構造に含まれていない古いフォルダを整理します。
**ファイルは絶対に削除されません**（移動のみ）。

### 使い方（必ず2段階で実行）

```bash
# 1. ドライラン: 何が移動・削除されるか確認（変更は一切しない）
python create_folders.py --cleanup --dry-run

# 2. 内容を確認して問題なければ実行
python create_folders.py --cleanup
```

### 整理のルール

| フォルダの状態 | 処理 |
|--------------|------|
| ファイルが直接入っている | フォルダごと `_アーカイブ` へ移動 |
| サブフォルダだけ（ファイルなし） | 中を整理した後、空になったら削除 |
| 完全に空 | 削除 |

### 動作例

```
顧客フォルダ（整理前）              顧客フォルダ（整理後）
├── 01_会社情報   ← テンプレートにある   ├── 01_会社情報
├── 旧資料        ← テンプレートにない   ├── 02_決算・申告
│   └── 2020年                          └── _アーカイブ
│       └── 領収書                          └── 領収書  ← ファイルごと移動
│           ├── file1.pdf                       ├── file1.pdf
│           └── file2.pdf                       └── file2.pdf
└── 02_決算・申告
                                        ※「旧資料」「2020年」は空になったので削除
```

- `_アーカイブ` フォルダは顧客フォルダごとに作成されます（整理対象がある場合のみ）
- アーカイブ内のファイルは後から手動で正しい場所に整理できます

## スプレッドシートの形式

### シート1: 顧問先マスタ

| 顧問先コード | 顧問先名 | 区分 |
|------------|---------|------|
| 001 | 株式会社A | 法人 |
| 002 | 山田太郎 | 個人 |

### シート2: フォルダテンプレート

| 階層 | フォルダ名 | 対象区分 |
|-----|-----------|---------|
| 1 | 01_会社情報 | 共通 |
| 2 | ├─ 登記簿 | 共通 |
| 2 | ├─ 定款 | 法人 |
| 1 | 02_決算・申告 | 共通 |
| 2 | ├─ 法人税 | 法人 |
| 2 | ├─ 所得税 | 個人 |

## 対象区分の動作

| 対象区分 | 法人顧客 | 個人顧客 |
|---------|---------|---------|
| 共通 | ○ 作成 | ○ 作成 |
| 法人 | ○ 作成 | × スキップ |
| 個人 | × スキップ | ○ 作成 |
