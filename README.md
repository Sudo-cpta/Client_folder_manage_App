# 顧客フォルダ管理アプリ

Google ドライブ上の顧客フォルダを一括管理するアプリケーションです。

## 機能

- **統一フォルダ構成の管理**: テンプレートを作成して、全顧客フォルダに統一のサブフォルダ構成を適用
- **フォルダ構成の可視化**: 現在のテンプレートと各顧客のフォルダ構造を視覚的に確認
- **一括作成・修正**: テンプレートの変更を全顧客フォルダに一括反映
- **安全な一括削除**: テンプレートから削除されたフォルダは、中身が空の場合のみ削除

## セットアップ

### 1. Google Cloud Console での設定

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. Google Drive API を有効化
3. OAuth 2.0 クライアント ID を作成（ウェブアプリケーション）
   - 承認済みの JavaScript 生成元: `http://localhost:5173`
   - 承認済みのリダイレクト URI: `http://localhost:5173`

### 2. 環境変数の設定

`client/.env` ファイルを作成:

```env
VITE_GOOGLE_CLIENT_ID=your-google-client-id-here
```

### 3. 依存関係のインストール

```bash
npm run install:all
```

### 4. 開発サーバーの起動

```bash
npm run dev
```

- フロントエンド: http://localhost:5173
- バックエンド: http://localhost:3001

## 使い方

### 初期設定

1. 「Google でログイン」をクリックして認証
2. 顧客フォルダを格納する親フォルダの ID を入力
   - Google ドライブでフォルダを開き、URL の `/folders/` 以降の文字列がフォルダ ID です

### フォルダテンプレートの作成

1. 「フォルダを追加」ボタンでルートフォルダを追加
2. 各フォルダの「➕」ボタンでサブフォルダを追加
3. フォルダ名をクリックして編集
4. 「サンプルを読み込む」ボタンで標準的なテンプレートを読み込むことも可能

### テンプレートの適用

1. テンプレートを編集後、「全顧客に適用」をクリック
2. 以下の処理が自動的に行われます：
   - テンプレートに存在し、顧客フォルダにないサブフォルダを作成
   - テンプレートから削除され、かつ中身が空のサブフォルダを削除
3. 結果がモーダルで表示されます

### 新規顧客の追加

1. 顧客名を入力して「追加」をクリック
2. 現在のテンプレートが適用された状態で顧客フォルダが作成されます

## 技術スタック

- **フロントエンド**: React + TypeScript + Vite
- **バックエンド**: Node.js + Express + TypeScript
- **認証**: Google OAuth 2.0
- **API**: Google Drive API v3

## 注意事項

- フォルダの削除は、中身が空の場合のみ行われます（データ保護）
- テンプレートはブラウザの LocalStorage に保存されます
- アクセストークンは有効期限があるため、期限切れの場合は再ログインが必要です
