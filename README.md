# 年収の壁シミュレーター

SNS等での公開を想定した、単一HTMLファイルの年収の壁シミュレーターです。
サーバー不要・外部通信なしで動作します（`index.html` をブラウザで開くだけ）。

制度基準日：**2026年8月16日**／版数：**2026年8月版 rev.3**（PRレビュー反映済み）

## できること

- **年分の切替**（令和7年分〜令和10年分）。税制改正の施行時期で計算が分岐します
- **立場別の試算**：配偶者／19歳以上23歳未満の子／16〜18歳の子／23歳以上の子／単身
- **家族への影響**：あなたの年収が、扶養者（親・配偶者）の所得税・住民税をいくら増やすかを算出
- **社会保険の適用拡大タイムライン**：2026年10月の賃金要件撤廃、2027年10月以降の企業規模要件の段階的撤廃を反映
- **多子世帯の学費支援**：扶養する子が3人未満になることで失われる授業料減免額を試算
- **手取りカーブのグラフ**と各壁での手取り一覧
- **URLでの条件共有**

## 対応している制度

| 区分 | 内容 |
|---|---|
| 所得税 | 給与所得控除・基礎控除（令和7／令和8年度改正）・配偶者控除・配偶者特別控除・扶養控除・特定親族特別控除・勤労学生控除・復興特別所得税 |
| 住民税 | 所得割・均等割（森林環境税含む）・調整控除・非課税限度額 |
| 社会保険 | 健康保険／介護保険／子ども・子育て支援金／厚生年金（標準報酬月額の等級表を実装）／雇用保険 |
| 国民年金・国保 | 国民年金保険料（学生納付特例の分岐あり）・国民健康保険料（概算／自治体料率入力の2モード） |
| 学費支援 | 高等教育の修学支援新制度（多子世帯の授業料等減免） |

## 国民健康保険の扱い

料率が自治体ごとに大きく異なるため、2モードから選択できます。

| モード | 内容 |
|---|---|
| 概算（既定） | 所得割10.6%・均等割35,000円・平等割30,000円（40〜64歳は介護分を上乗せ）で計算し、結果に「±30%程度の幅」と**独自仮定である旨**を明示します |
| 自治体の料率を入力 | 所得割率・均等割・平等割・賦課限度額を利用者が入力します。市区町村ホームページでの調べ方を画面上に案内します |

均等割・平等割の軽減（7割／5割／2割・令和8年度の乗算額31万円／57万円）を単身世帯として判定します。
国保が実際に発生する条件（扶養から外れ、勤務先の社会保険にも入らない）になったときだけ、
概算である旨と金額の幅を利用者に警告します。**公式な全国標準値は存在しない**ため、概算モードの
料率は本ツール独自の仮定値である旨を画面上に明示しています。令和8年度から医療分・後期高齢者支援金分・介護納付金分・子ども子育て支援納付金分の4区分となり、
賦課限度額は区分別（医療67万・支援26万・介護17万・子ども子育て支援3万）に適用されます。
本ツールは該当区分の合計額（40歳未満96万円／40〜64歳113万円）で判定しています。

## 主な壁の位置（令和8年分・給与収入）

| 年収 | 壁 |
|---|---|
| 119万円 | 住民税がかかり始める |
| 130万円 | 健康保険の被扶養者認定（配偶者・23歳以上など） |
| 136万円 | 扶養控除・配偶者控除の所得要件（合計所得62万円） |
| 150万円 | 健康保険の被扶養者認定（**配偶者を除く19〜22歳**・2025年10月1日以降） |
| 159万円 | 特定親族特別控除（63万円）の逓減開始 |
| 169万円 | 多子世帯の「子ども」に算入される上限（19〜22歳・合計所得95万円） |
| 169万円 | 配偶者特別控除（38万円）の逓減開始 |
| 178万円 | 所得税がかかり始める |
| 197万円 | 特定親族特別控除の消滅 |
| 207万円 | 配偶者特別控除の消滅 |

社会保険の「106万円の壁」は 2026年10月の賃金要件撤廃により消滅し、週20時間以上が主要な判定要件になります。
健康保険の被扶養者認定基準（130万円）は継続しますが、**配偶者を除く19歳以上23歳未満は
2025年10月1日以降の認定から150万円未満**に引き上げられています（学生であることは要件ではありません）。

## 制度パラメータの更新

すべての制度パラメータは `index.html` 内の `<script>` 冒頭に集約してあります。

- `BASIS_DATE` / `REVIEW_DUE` — 制度基準日と見直し期限。期限を過ぎると画面上部に注意バーが自動表示されます
- `YEARS` — 年分ごとの給与所得控除・基礎控除・所得要件
- `HAIGUSHA_TOKUBETSU_I` / `TOKUTEI_SHINZOKU` / `FUYO_KOJO` — 各控除の段階表
- `REGIMES` / `REGIME_BY_YEAR` — 社会保険の適用拡大タイムライン
- `STD_GRADES` — 標準報酬月額の等級表
- `TUITION_CAP` — 授業料減免の上限額
- `JINTEKI_SA` — 調整控除の人的控除差（**所得税と住民税の控除額の実差ではなく地方税法上の定額**。特定親族特別控除・配偶者特別控除は0円）
- `KOKUHO_ESTIMATE` / `KOKUHO_KEIGEN` — 国保の概算仮定と軽減判定
- `VERSION` / `CHANGELOG` — 版数とフッタに表示する更新履歴
- `SITE` — 事務所名・URL・問い合わせ先。**空のままなら「提供」欄は表示されません**（誤った情報が公開されないための既定値）

保険料率・国保・住民税の各パラメータは画面上の「詳細パラメータ」から利用者が変更できます。

**更新サイクル：毎年1月（税制改正大綱の反映）および4月（保険料率改定の反映）**

## テスト

計算エンジンは `index.html` から直接抽出して検証しています（出荷するコードそのものをテストします）。

```
node test-engine.mjs
```

各年分の非課税ライン、控除の段階表、標準報酬月額の等級判定、社会保険の適用拡大タイムライン、
壁の金額換算など141件のアサーションを含みます。うち一次資料監査に対応する検証は、
給与所得控除の境界帯、住民税の控除の下限（58万→62万）、基礎控除2,350万円超の逓減、
調整控除の人的控除差、国保の平等割と軽減の5系統です。

## 公開時にやること

公開先： https://www.oshieteyosshi.com/nenshu-kabe/ （想定パス）

1. `index.html` と `ogp.png` を**同じフォルダに**アップロードする
2. パスが `/nenshu-kabe/` 以外になる場合は、`index.html` 冒頭の `og:url` と `og:image` を実際のURLに書き換える
3. 制度を更新したら `VERSION` と `CHANGELOG` を更新する

`SITE`（事務所名・問い合わせ先）は空のままにしています。事務所サイト内に設置するため、
周囲に事務所の情報がある前提です。単体で配布する場合はここを設定してください。

## 既知の近似

- 国民健康保険の賦課限度額は本来は区分別（医療67万・支援26万・介護17万・子ども子育て支援3万）に
  適用されますが、本ツールは該当区分の合計額（40歳未満96万円／40〜64歳113万円）で判定しています
- 健康保険の被扶養者認定は、入力された年収による単純判定で近似しています
  （2026年4月以降の労働契約上の賃金による認定方式には対応していません）
- 住民税の非課税限度額に用いる扶養親族の数は、扶養者側について「本人が扶養の所得要件を
  満たすかどうか」のみで数えており、他の家族構成は考慮していません
- 給与収入220万円〜660万円未満について、国税庁「給与所得控除後の給与等の金額の表」の
  4,000円区分による丸めを行わず、計算式で1円単位に算出しています（給与所得で最大1,400円程度、
  税額で数百円程度の差）。壁の位置には影響しません
- 国民健康保険の軽減判定は単身世帯・給与所得者1人を前提としています
- 令和7年分・令和10年分には給与所得控除の境界帯の定額処理を実装していません
  （令和8・9年分のみ国税庁Q&Aで数値が確定しているため）

## 免責

本ツールは概算です。給与所得者のみを前提とし、賞与・複数勤務先・年の途中の就退職・個人事業所得・
年金収入・各種所得控除は考慮していません。国民健康保険料および住民税の非課税限度額は自治体により
異なります。実際の税額・保険料額および個別のご判断については、必ず税理士・社会保険労務士・
お住まいの市区町村にご確認ください。
