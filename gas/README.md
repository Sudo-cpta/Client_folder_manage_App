# GAS版 顧問先フォルダ作成（スプレッドシートのボタンで実行）

「顧問先フォルダマスタ」スプレッドシートにボタンを設置し、クリックだけで
Googleドライブに顧客フォルダを一括作成します。**PC・Python・git・PowerShell は不要**です。

- 読み取り元: 同じスプレッドシートの「顧問先マスタ」「フォルダテンプレート」シート
- 作成先: 初回に入力する「親フォルダID」の下
- 既存フォルダはスキップ（重複しない）。削除・移動はしない（作成のみ）

---

## 設置手順（初回のみ・所長の操作）

### 1. Apps Script を開く

1. 「顧問先フォルダマスタ」スプレッドシートを開く
2. メニュー **拡張機能 → Apps Script** をクリック

### 2. コードを貼り付ける

1. 最初から入っている `function myFunction() {}` を**全部削除**
2. このフォルダの **`create_folders.gs` の中身を全部コピーして貼り付け**
3. 左上の **💾（保存）** をクリック（プロジェクト名は「フォルダ作成」などでOK）

### 3. メニューを表示する

1. スプレッドシートの**タブに戻り、ページを再読み込み**（F5）
2. 上部メニューに **「フォルダ管理」** が追加される

### 4. 初回実行と承認

1. **フォルダ管理 → フォルダ作成** をクリック
2. 初回は「承認が必要です」と出る → **承認** → 自分のGoogleアカウントを選択
3. 「このアプリは Google で確認されていません」と出たら
   **詳細 → （プロジェクト名）に移動 → 許可**
4. 「親フォルダID」を聞かれるので入力（次回以降は不要）
5. フォルダ作成が始まり、終わると件数が表示される

---

## ボタンを設置する（任意・メニューでも実行できます）

1. スプレッドシートで **挿入 → 図形描画**
2. 四角を描いて「フォルダ作成」と文字を入れる → **保存して終了**
3. シート上に置かれた図形をクリック → 右上の **⋮ → スクリプトを割り当て**
4. `createFolders` と入力して **OK**
5. 以降、その図形（ボタン）を押すとフォルダ作成が走る

---

## 使い方（2回目以降）

- ボタン、または **フォルダ管理 → フォルダ作成** を押すだけ
- 顧問先を追加したら押せば、その顧客のフォルダだけ新規作成される（既存はスキップ）

## 補足

- **6分制限対策**：顧客数が多く途中で時間切れになった場合は
  「続きから再開します」と表示されます。もう一度押せば続きを作成します。
- **親フォルダIDを変えたい**：フォルダ管理 → 親フォルダIDを再設定
- **共有ドライブ**：共有ドライブ内のフォルダIDでも動作します。
  もし「見つかりません」等のエラーが出る場合はご連絡ください（Drive API 版に切替可能）。
- Python版（`python/create_folders.py`）はバックアップとして残していますが、
  今後の運用はこのGAS版に一本化します。
